النص العربي لـ Affinity — الإصدار 1.3
https://github.com/mahdidigitalx-oss/affinity-arabic-text

التثبيت:
1. شغّل install.cmd بنقرة مزدوجة (لا يحتاج صلاحيات المدير).
2. في Affinity: Settings > Scripting، تأكد أن البرامج النصية مفعّلة.
3. في لوحة Scripts Library: اضغط زر القائمة بجانب مجموعة Default، ثم اختر Import Script...، ثم اختر الملف Arabic-Text.afscript.
4. إن كان Affinity مفتوحاً أثناء التثبيت، فأغلقه وافتحه مرة واحدة.

الاستخدام:
- نص جديد: لا تحدد شيئاً، ثم انقر نقراً مزدوجاً على «النص العربي» في لوحة Scripts Library.
- تعديل نص: حدّد الشكل العربي، ثم شغّل الأداة.

الإزالة: شغّل uninstall.cmd، ثم احذف «النص العربي» من لوحة Scripts Library.

----------------------------------------------------------------
Arabic Text for Affinity 1.3 (Windows, Affinity 3 by Canva)

Install:
1. Double-click install.cmd (no admin rights needed).
2. In Affinity, enable scripting under Settings > Scripting.
3. In the Scripts Library panel, open the menu next to the Default category, choose
   Import Script..., and pick Arabic-Text.afscript.
4. If Affinity was open during the install, close it and open it again once.

Uninstall: run uninstall.cmd, then delete the script from the Scripts Library panel.
